GOLF IS A GAME OF FEEL.

Prestiege Country Club is a browser-based 3D golf project built for a school presentation. It uses the Three.js 3D engine for the golf course, golfer, ball flight, terrain, trees, bunkers and water hazards.

This is an independent school project. Not affiliated with PGA TOUR or 2K. Online accounts and cloud saves require a database integration in a later phase.
