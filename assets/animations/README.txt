PRESTIEGE COUNTRY CLUB - ANIMATION PACK

Extract this folder to assets/animations/ OR upload the archive itself to assets/animations.zip.
The V4 game code can load either layout.

Core golf:
Breathing Idle.fbx, Golf Drive.fbx, Golf Chip.fbx, Golf Putt.fbx, Walking.fbx, Running (1).fbx, Golf Tee Up.fbx, Picking Up.fbx

Coach Timmy / reactions:
Talking.fbx, Pointing Forward.fbx, Pointing Gesture.fbx, Waving.fbx, Clapping.fbx, Cheering.fbx, Angry.fbx, Sitting Thumbs Up.fbx

Celebrations:
Breakdance Uprock.fbx, Breakdance Footwork To Idle.fbx, Breakdance Freeze Var 3.fbx

The project uses Three.js FBXLoader and retargets matching Mixamo-style bone names. Different model skeletons may require retargeting adjustments.
